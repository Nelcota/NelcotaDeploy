## How to run

```bash
make tools          # also installs templ v0.3.1020 and the checksum-verified Tailwind v4.3.3 CLI
make web            # templ generate → Tailwind → fingerprinted Brotli/zstd assets (committed output)
make build test lint
make dev-seed
make dev            # http://127.0.0.1:8080 → "Continue as development administrator"
```

Real passkeys need a domain-name origin: `NELCOTA_DEV_ORIGIN=http://localhost:18080 NELCOTA_DEV_LISTEN=127.0.0.1:18080 bin/nelcota-panel dev`.

Browser tests (Node required only here and for `make web-vendor`):

```bash
cd web && npm ci && npx playwright install chromium && cd ..
make e2e                                                  # starts its own dev panel on :18181
cd web && SCREENSHOTS=1 npx playwright test e2e/screenshots.spec.js   # regenerates docs/screenshots
```

## Design

Dark-first, simple layout inspired by the maintainer's reference: an icon rail (a bottom tab bar on phones), one large rounded content panel, pastel stat tiles, rounded rows with a thumbnail, status bar, and action cells. Copy is short and plain; decorative icons, uppercase micro-labels, and animations were removed. Light and dark themes share the structure; the rail toggles the theme and Account › Appearance offers System/Light/Dark. See [decisions](decisions.md#frontend-october-16-2026).

## Architecture in brief

- Pages are templ components rendered by handlers in `web/` that call `service.Services`. Datastar 1.0.4 runs in nonce mode under a per-request CSP (`script-src 'self' 'nonce-…'`, no `unsafe-eval`; inline styles only on the logs page for xterm.js).
- Mutations are Datastar form posts to `/ui/*` with the `X-CSRF-Token` header, behind the existing Origin/CSRF middleware; responses are SSE patches and toasts. WebAuthn uses the documented `/api/auth/*` endpoints.
- Live pages open `/ui/stream/...`, which sends a full snapshot on every connection, applies hub events, rechecks credentials every 15 s, and ends when the hub drops a slow consumer (Datastar reconnects with backoff). Logs and charts use `EventSource` on `/api/events`.
- Assets are embedded from `web/static/dist` with content-hashed names, Brotli and zstd variants, and `Cache-Control: public, max-age=31536000, immutable`. `make web` is deterministic (verified by rebuilding and comparing checksums).

## Backend changes

All changes are small, tested, and listed in [backend changes](backend-changes.md):

- `Auth.Factors` and `Auth.RemovePasskey` for passkey/TOTP management (own account, fresh session for removal, last passkey protected, audited).
- `web.Register(r, web.Config{...})` with CSRF and stream-revalidation callbacks from `internal/httpapi`, plus `httpapi.Config.Version`.
- `NELCOTA_DEV_ORIGIN` / `NELCOTA_DEV_LISTEN` for development (passkeys need a domain name).
- Varying simulated metrics with container samples in development mode.
- One remaining Portuguese API message ("JSON adicional") translated to English.
- `go.mod`: `github.com/a-h/templ` v0.3.1020 and `github.com/andybalholm/brotli` v1.2.0 (asset precompression).

## Outstanding work

- **Acceptance on real infrastructure:** real passkeys on phones and laptops, Safari and Firefox (only Chromium was tested), a VPS panel with real agents, WAN latency, and the GitHub App manifest round trip.
- **Backend gaps that remain:** the GitHub callback returns JSON (a friendly redirect needs a backend change); the panel doesn't know servers' public IPs, so the DNS check reports where a domain points without judging it; external notifications are phase 2; operations have no event stream (the UI polls every 4 s while jobs run). Cache usage, failure reasons, branch heads, and team management were added.
- **Interface limits:** metric charts start empty on each page load because samples are not persisted; the audit page filters the newest 1000 entries (service limit); browser log streams can miss lines when the hub drops a saturated consumer (documented backend boundary; build logs reload the stored snapshot on reconnect).
- **Tooling:** `templ fmt` v0.3.1020 fails on these files, so `.templ` formatting is not enforced; own scripts are not minified.
